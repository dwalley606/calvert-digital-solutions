# CDS Website

This directory is the runnable Next.js application. Run npm commands here, not at the repository root.

See the [canonical project README](../../README.md) for setup, routes, architecture, design system, environment variables, integrations, validation, deployment requirements, and pending work.

App entry points:

- [package.json](package.json): scripts and dependencies.
- [.env.example](.env.example): environment-variable template; keep real credentials in ignored local/deployment configuration.
- [src/app](src/app): routes, root layout, theme, and local fonts.
- [CLAUDE.md](CLAUDE.md): concise implementation guidance for coding agents.
